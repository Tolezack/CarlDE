# Repositório de plugins CarlDE

Conteúdo pronto para um repositório **público** no GitHub.

1. Crie `seu-usuario/carlde-plugins` no GitHub.
2. Copie/publique **o conteúdo desta pasta** na raiz da branch `main`.
3. Abra o **CarlDE → PLUGINS** e informe `seu-usuario/carlde-plugins` e `main`.
4. Clique em **ATUALIZAR CATÁLOGO** e instale/desative/ative plugins pela tabela.

Depois de qualquer alteração, execute `python3 build_catalog.py` e publique o novo `index.json` com as mudanças.

Inclui exemplos: OpenTK, AutoCorrigir, Formatador, Git Tools.

**Segurança:** A extensão Python roda com suas permissões. Avalie o código antes de instalar extensões de terceiros.
